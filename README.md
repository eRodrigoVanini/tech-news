## :clipboard: Page Purpose
This project is a static webpage that simulates a technology news portal. The main objective was to apply and deepen my knowledge of semantic HTML5 and, most importantly, modern layout and styling techniques with CSS.

<br>

## :computer: Technologies Used
- HTML and CSS    
<br>

## 🚀 Concepts Practiced and Learned

During the development of this page, I focused on practicing and learning the following features:

* **Semantic HTML5:** Correct use of tags like `<article>`, `<figure>`, and `<figcaption>` to structure the news content in a meaningful and accessible way.
* **CSS Grid Layout:** Application of `display: grid` as the primary tool for creating a complex and responsive layout, organizing the news cards and page sections.
* **Multi-Section Structure:** Organizing the layout into different logical components (such as the header, main content, sidebar, etc.), each with its own structure.
* **`:hover` Pseudo-class:** Adding interactivity effects to provide visual feedback to the user, such as color or shadow changes when hovering over the news cards.
* **CSS `linear-gradient`:** (✨ New skill!) I explored the use of `linear-gradient` to create backgrounds with color gradients, applying a more modern and dynamic look to the page elements.

This project served as an excellent practical exercise to consolidate the use of semantic HTML5 tags and explore the power of CSS Grid combined with other styling features.
